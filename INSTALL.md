# Автоматическое расписание СКИ РУК

Группа ЮР(ЮР)2-О/Бп/СР25, Саранский филиал, набор 2025.

## Установка в существующий репозиторий

Скопируйте содержимое архива в корень репозитория neironkaworkegor-ctrl/raspisanie с заменой index.html. Обязательно перенесите скрытую папку .github. Не загружайте сам ZIP вместо файлов.

В Settings → Pages → Build and deployment → Source выберите GitHub Actions. Ссылка сайта и кнопка Telegram останутся прежними.

После сохранения файлов откройте Actions → Update RUC schedule and publish → Run workflow. Дождитесь успешного выполнения и откройте сайт. Внизу появится время проверки РУК. Для проверки можно выбрать 30 декабря 2026 — источник указывает зачёт по профессиональной этике в аудитории 100б.

Если GitHub сообщает запрет на запись, в Settings → Actions → General проверьте разрешение запуска workflows. Workflow требует contents: write для сохранения расписания, pages: write и id-token: write для публикации. Ограничения организации и защиты main могут потребовать настройки владельцем.

## Работа

- Источник — https://schedule.ruc.su/. Запрашиваются отдельные реальные недели, без повторения шаблонов.
- Проверка запускается на 17-й и 47-й минуте каждого часа по UTC. GitHub может задерживать или пропускать запуск при нагрузке. В публичных репозиториях расписание Actions отключается после 60 дней отсутствия активности репозитория. Проверяйте успешные запуски в Actions, при необходимости включите workflow снова.
- Загружаются предыдущая неделя, текущая и следующие 12 недель. Ранее загруженные даты сохраняются. Диапазон можно расширить аргументом --future-weeks.
- Пустые дни показываются как «На сайте РУК занятия на этот день не указаны». Это может означать отсутствие занятий или ещё не опубликованное расписание.
- При ошибке отдельной недели её последние данные сохраняются. При полном сбое сборщика публикуется существующий JSON, а запуск помечается ошибкой.
- Открытая страница перечитывает опубликованные данные каждую минуту и при возвращении в приложение. Кнопка «Обновить» перечитывает последнюю опубликованную версию, не запускает новый запрос к РУК.
- У выбранной даты показывается время проверки. Через два часа без обновления появляется отметка о возможном устаревании.
- Успешно загруженные данные сохраняются в браузере для временного отсутствия связи. Для первой загрузки нужен интернет.
- При изменении HTML-разметки сайта РУК сборщик может потребовать адаптации. Неполные ответы и неверно выбранная группа отклоняются.

## Проверка вручную

Требуется Python 3.9+ с базой часовых поясов, без сторонних Python-пакетов.

```sh
python scripts/sync_schedule.py
```

Для локального просмотра запустите HTTP-сервер из папки сайта. Открытие index.html через file:// не поддерживает загрузку JSON во всех браузерах.

## Что проверено

Реальные ответы РУК, поля преподавателей и аудиторий, зачёт на 30.12.2026, отклонение ошибочных ответов, переключение дат и недели, сохранение расписания при ошибке сети. Публикация GitHub Actions требует авторизации владельца и пока не выполнена.
